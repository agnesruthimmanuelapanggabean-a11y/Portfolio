## Featured Projects

### 01. Automated KPEI Trading Limit Monitoring

A web-based tool designed to streamline a recurring collateral monitoring and reporting process within securities operations.

#### Business Challenge

KPEI trading-limit monitoring was performed manually three times a day and involved several repetitive steps. This created operational inefficiencies and increased exposure to human error, such as missed updates or inconsistencies in recorded figures.

#### Solution

Developed a centralized web-based interface that combines trading-limit calculations, discrepancy checks, narrative generation, screenshot capture, and daily reporting in a single workflow, eliminating the need to manually move information across multiple tabs and reporting files.

#### Key Features

- Compare system and manual trading-limit calculations
- Automatically generate standardized monitoring narratives
- Store monitoring captures by time slot
- Consolidate daily monitoring results
- Automate report submission to Google Drive

**Tools:** `Python` `JavaScript` `HTML/CSS` `Google Apps Script`

### 02. Special Client Narrative Generator

A web-based tool for processing daily client monitoring data and generating standardized margin call narratives.

#### Business Challenge

Daily Special Client monitoring required manually processing client monitoring data, verifying autodebet information, and preparing standardized margin call narratives to be sent directly to clients. The complexity of the process increased the risk of human error, particularly in data and billing information, which could potentially expose the company to reputational and credit risks.

#### Solution

Developed a web-based tool that converts raw monitoring data copied from Excel into a structured review interface, where client information and billing figures can be validated, client categories and autodebet status are identified, and standardized margin call narratives are generated automatically.

#### Key Features

- Process data copied from Excel
- Automatically identify monitored clients
- Review and edit client information
- Categorize Family/Stakeholder and Non-Family clients
- Identify clients requiring additional checks
- Generate ready-to-send narratives

**Tools:** `JavaScript` `HTML/CSS` `AI-assisted development`

### 03. Automated Stock Reporting Generator

A web-based reporting tool that streamlines the monitoring and reporting of stocks under special monitoring (UMA) and changes in KPEI haircut requirements.

#### Business Challenge

Daily stock monitoring and reporting required compiling information on monitored stocks and KPEI haircut changes, then preparing and distributing a standardized report across different channels. The manual process created unnecessary administrative work and increased the risk of omissions or inconsistent reporting.

#### Solution

Developed a structured reporting interface that allows users to record monitored stocks and KPEI haircut changes in a standardized format, automatically generate the daily reporting template, and save the finalized output directly to Google Drive.

#### Key Features

- Record stocks under special monitoring (UMA)
- Record changes in KPEI haircut requirements
- Organize stock monitoring information in a standardized format
- Generate ready-to-copy reporting outputs
- Automate saving generated reports to Google Drive

**Tools:** `Python` `JavaScript` `HTML/CSS` `Google Apps Script`
